## 2026-05-17 - Avoid cryptographic rng for general simulations
**Learning:** The codebase was using `secrets.SystemRandom().randint()` for generating call metrics (duration, waves, intervals) which is a cryptographic operation reading from system entropy (`/dev/urandom`). This adds massive overhead to rapid generation in large-scale simulation threads compared to a pseudo-random number generator.
**Action:** Use standard `random.randint()` for statistical/simulation randomization tasks where cryptographic security is not required, resulting in up to 5-6x speedup in standalone number generation overhead.
## 2024-06-09 - Optimize CallStatistics dictionary lookups using EAFP
**Learning:** In this codebase's statistical aggregators (e.g., `CallStatistics`), use the EAFP pattern (`try...except KeyError`) instead of LBYL (`if key not in dict`) and assign nested dictionaries to local variables for dictionary operations in hot loops to significantly reduce execution overhead during benchmarking and simulation.
**Action:** Always favor EAFP (`try...except KeyError`) and local variable caching over LBYL (`if key not in dict`) and repeated dictionary lookups in tight inner loops, specifically within statistical tracking methods.
